# Weibo Scraper API – code examples

Examples for every Weibo endpoint of the [Piloterr API](https://www.piloterr.com). Python and TypeScript examples are in the [main README](../README.md).

```bash
export PILOTERR_API_KEY="your-api-key"   # get one at https://app.piloterr.com
```

| Language | File | Run |
|---|---|---|
| cURL (Bash) | [`curl/post_info.sh`](curl/post_info.sh) | `bash post_info.sh` |
| cURL (Bash) | [`curl/search.sh`](curl/search.sh) | `bash search.sh` |
| PHP | [`php/post_info.php`](php/post_info.php) | `php post_info.php` |
| PHP | [`php/search.php`](php/search.php) | `php search.php` |
| C# | [`csharp/PostInfo.cs`](csharp/PostInfo.cs) | `copy to `Program.cs`, `dotnet run` |
| C# | [`csharp/Search.cs`](csharp/Search.cs) | `copy to `Program.cs`, `dotnet run` |
| Go | [`go/post_info.go`](go/post_info.go) | `go run post_info.go` |
| Go | [`go/search.go`](go/search.go) | `go run search.go` |
| Java | [`java/PostInfoExample.java`](java/PostInfoExample.java) | `java PostInfoExample.java` |
| Java | [`java/SearchExample.java`](java/SearchExample.java) | `java SearchExample.java` |
| Ruby | [`ruby/post_info.rb`](ruby/post_info.rb) | `ruby post_info.rb` |
| Ruby | [`ruby/search.rb`](ruby/search.rb) | `ruby search.rb` |
| Node.js | [`nodejs/post_info.mjs`](nodejs/post_info.mjs) | `node post_info.mjs` |
| Node.js | [`nodejs/search.mjs`](nodejs/search.mjs) | `node search.mjs` |
